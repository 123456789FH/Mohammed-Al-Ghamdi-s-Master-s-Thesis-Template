# نموذج الماستر كوتش: محمد الغامدي — PWA

تطبيق ويب تفاعلي للكوتشنج الطلابي، جاهز للنشر على GitHub Pages، ويتضمن:

- المراحل الخمس: أطمح، أهتم، أربط، أخطط، أنفذ.
- حفظ إجابات المستفيد والتقدم محليًا على الجهاز.
- متابعة الإنجاز والخطة الأسبوعية والشارات.
- مكتبة موارد فعلية: موارد مرفقة مع المستودع + إضافة ملفات وروابط من داخل التطبيق.
- الملفات التي يرفعها المستخدم من داخل التطبيق تحفظ في IndexedDB على الجهاز نفسه ولا تُرفع إلى GitHub.
- دعم PWA: manifest + service worker + أيقونات + تثبيت على الأجهزة + تخزين مؤقت للعمل دون اتصال للأجزاء الأساسية.

## النشر على GitHub Pages

1. ارفع جميع الملفات والمجلدات الموجودة في هذه الحزمة إلى جذر المستودع، بما فيها:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.json`
   - `service-worker.js`
   - مجلد `icons`
   - مجلد `resources`
2. من Settings → Pages اختر النشر من الفرع المطلوب.
3. بعد ظهور رابط GitHub Pages، افتحه مرة واحدة وانتظر تحديث الصفحة.
4. في حال وجود نسخة قديمة مخزنة، نفّذ تحديثًا قويًا للصفحة أو امسح بيانات الموقع مرة واحدة حتى يتم استبدال الـ Service Worker القديم.

## التثبيت

- iPhone / iPad: Safari → مشاركة → إضافة إلى الشاشة الرئيسية.
- Android / Chrome: يظهر خيار تثبيت التطبيق أو Add to Home screen.
- Windows / macOS عبر Chrome أو Edge: خيار Install app في شريط العنوان أو قائمة المتصفح.

## ملاحظة مهمة عن مكتبة الموارد

- الموارد داخل مجلد `resources` عامة لكل مستخدمي التطبيق.
- الملفات التي يضيفها المستخدم بزر «إضافة مورد» تحفظ محليًا على ذلك الجهاز/المتصفح باستخدام IndexedDB.
- لمزامنة الملفات بين جميع الأجهزة أو السماح للماستر بإدارة مكتبة مركزية من داخل التطبيق، يلزم ربط التطبيق بخدمة تخزين/قاعدة بيانات مثل Supabase أو Firebase أو خدمة خلفية مشابهة.
