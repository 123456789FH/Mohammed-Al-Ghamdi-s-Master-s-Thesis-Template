# نموذج الماستر كوتش: محمد الغامدي

تطبيق ويب تفاعلي عربي للكوتشنج الطلابي، مبني بـ HTML/CSS/JavaScript فقط، دون أي مكتبات خارجية.

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8080
```
ثم افتح:
`http://localhost:8080`

## الرفع إلى GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/root` ثم Save.

## الملفات
- `index.html` واجهة التطبيق.
- `styles.css` التصميم والهوية البصرية.
- `app.js` التفاعلات، الحفظ المحلي، حساب التقدم، التنقل.
- `manifest.json` تهيئة كتطبيق ويب قابل للتثبيت.

## المزايا الحالية
- خمس مراحل تفاعلية: أطمح، أهتم، أربط، أخطط، أنفذ.
- حفظ الإجابات محليًا باستخدام LocalStorage.
- حساب نسبة الإنجاز تلقائيًا.
- شاشة متابعة التقدم.
- قائمة متابعة أسبوعية.
- شارات إنجاز.
- ملف مستفيد بسيط.
- تصميم RTL ومتجاوب مع الجوال والتابلت والكمبيوتر.
